# CycleSync — Legal

Public mirror of the legal documents for the [CycleSync](https://github.com/teleng-labs/cyclesync-ios) iOS + Apple Watch wellness app.

Hosted via GitHub Pages at **https://teleng-labs.github.io/cyclesync-legal/**:

- Index — https://teleng-labs.github.io/cyclesync-legal/
- Privacy Policy — https://teleng-labs.github.io/cyclesync-legal/privacy/
- Terms of Use — https://teleng-labs.github.io/cyclesync-legal/terms/

The CycleSync app is private by default: 100% on-device, no backend, no accounts, no analytics, no advertising trackers, no third-party SDKs. The site explains the policy and the engineering choices that make it true.

## Source of truth

The canonical markdown for these documents lives in the private app repo at `docs/legal/`. The files here (`_PRIVACY_POLICY.md`, `_TERMS_OF_USE.md`) are kept in sync from there. The HTML pages under `privacy/` and `terms/` are generated by `_build.py`.

To regenerate after editing the markdown:

```bash
python3 _build.py
```

## Stack

Plain HTML + CSS, no framework. Fonts via Google Fonts (Fraunces, Inter Tight, JetBrains Mono). `.nojekyll` disables GitHub's Jekyll pipeline so the site is served exactly as committed.
